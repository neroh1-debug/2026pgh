# 2026학년도 자율형공립고 2.0 자체평가회 — 지나온 성장, 함께할 도약

포천일고 인터랙티브 발표와 같은 방식(같은 색·글꼴)으로 만든 30장짜리 웹 발표입니다.
선생님들은 QR로 접속해 이름을 입력하면 분임에 자동 배정되고, 휴대폰에서 발표 화면을 계속 보면서 중간중간 응답하고 토의 결과를 기록합니다.

## 실행

`시작.bat`을 더블클릭합니다. 또는 이 폴더에서 다음을 실행합니다(Node.js 18 이상).

```
npm install   (처음 한 번만)
npm start
```

| 화면 | 주소 |
|---|---|
| 발표 화면 (빔프로젝터) | `http://<노트북 IP>:8080/presenter`, 핀코드 **0821** |
| 참여자 (휴대폰) | 화면의 QR 스캔, 또는 `http://<노트북 IP>:8080/` |

> 휴대폰과 노트북이 **같은 Wi-Fi**에 있어야 합니다. 학교 Wi-Fi가 기기 간 통신을 막으면 노트북을 휴대폰 핫스팟에 연결하거나, 아래 "외부 공개"를 사용하세요.

## 행사 전 준비: 교사 명단 넣기

이름을 입력하면 분임이 자동 배정되도록 명단을 넣어 둡니다. 둘 중 편한 방법을 쓰세요.

1. **발표자 화면 → 툴바 `분임 관리`(G 키)**: 엑셀에서 `이름 | 분임 | 분임장(O) | 비고` 네 열을 복사해 붙여넣고 **명단 저장**.
2. `roster.csv` 파일을 직접 고친 뒤 서버 시작 (서버를 처음 켤 때만 읽습니다. `state.json`이 있으면 그쪽이 우선).

- 분임 칸은 `3`, `3분임` 모두 됩니다.
- 분임장 칸에 `O`를 넣은 선생님이 그 분임의 기록 담당이 됩니다. 비워 두면 분임원 중 한 명이 휴대폰에서 **내가 분임장으로 기록할게요**를 눌러 맡습니다(먼저 누른 한 명).
- 동명이인은 비고(교과 등)를 적어 두면 입장할 때 골라서 들어옵니다.
- 명단에 없는 이름은 분임을 직접 골라서 들어옵니다. 명단을 넣지 않으면 모두 직접 고릅니다.

## 진행 순서와 인터랙션

| 쪽 | 내용 | 휴대폰에서 |
|---|---|---|
| 1~3 | 표지 · 참여 안내(큰 QR, 실시간 입장 인원) · 진행 순서 | 입장 |
| 4 | 올 한 해 우리 학교를 한 단어로 | 단어 3개 → 워드클라우드 |
| 5~9 | **01 설문결과 소개** (보고서의 교육주체 설문 수치) | |
| 10~13 | **02 분임별 주제토의**: 분임 구성 · 토의 진행 방법 · 타이머 | `우리 분임` 탭: 개인 의견 → 모두의 의견 보기 → 분임장 최종 의견 |
| 14~23 | **03 토의결과 공유**: 한눈에 보기 + 분임별 1장씩 | 최종 의견 읽기 · ♥ 공감 · 댓글 |
| 24~26 | **04 차년도 교육활동 의견수렴** | 바라는 점(익명, 3개) · 다짐 한 단어 |
| 27 | 감사합니다 | |

### 분임 토의 (13쪽 타이머 화면)

- 화면 위쪽 조작판에서 10~30분 선택 → **▶ 시작**(T 키) / +1분 / 처음으로. 남은 시간은 선생님 휴대폰 위쪽에도 표시됩니다.
- 이 화면이 되면 휴대폰은 자동으로 **우리 분임** 탭으로 넘어갑니다.
- 진행 순서 (휴대폰 **우리 분임** 탭)
  1. **① 나의 의견**: 분임원 각자 좋았던 점 · 개선할 점 · 2027학년도 실천 제안 입력 (자동 저장)
  2. **② 우리 분임 의견 모아보기**: **모두의 의견 보기** 버튼으로 분임원 전원의 의견을 항목별로 함께 보며 말로 토론
  3. **③ 분임 최종 의견**: 분임장이 토론 내용을 요약해 작성 → **최종 의견 제출 · 전체 공유**. 분임원은 실시간으로 확인
- 개인 의견은 같은 분임 선생님과 발표자에게만 보이고, 전체 화면에는 분임장의 최종 의견만 나옵니다.
- 오른쪽 목록에서 분임별 상태(의견 N명 입력 → 작성 중 → 제출 완료)를 확인할 수 있습니다.

### 결과 공유 (15~23쪽)

- 15쪽 카드를 클릭하면 그 분임 화면으로 바로 갑니다.
- 분임 화면에는 최종 의견과 함께 **공감 ♥ 수**와 **최근 댓글 4개**가 실시간으로 표시됩니다. 댓글에 마우스를 올리면 나오는 ✕로 숨길 수 있습니다.
- 휴대폰에서는 최종 의견을 크게 읽고, **♡ 공감**과 **댓글**(기본 익명, 체크 해제 시 이름 표시)을 남깁니다.

### 의견 벽 (28쪽)

- 의견 카드를 클릭하면 화면 가운데 크게 띄웁니다(다시 클릭하면 내림). 카드에 마우스를 올리면 나오는 ✕로 부적절한 의견을 숨길 수 있습니다.

## 발표자 조작

| 키 | 동작 |
|---|---|
| → / Space / PageDown / Enter | 다음 (프레젠터 리모컨 가능) |
| ← / PageUp | 이전 |
| 숫자 입력 후 Enter | 해당 쪽으로 이동 |
| F | 전체화면 |
| R | 애니메이션 다시 재생 |
| Q | QR 카드 접기/펼치기 (클릭하면 크게) |
| M | 질문 목록 |
| G | 분임 관리 (명단, 분임장 해제, 결과 다운로드) |
| A | 정답 확인/숨기기 (퀴즈) |
| T | 타이머 시작/일시정지 (15쪽) |

- 툴바 **응답 초기화**는 현재 쪽의 응답만 지웁니다(리허설 후 사용).
- **분임 관리 → 결과 CSV 다운로드**: 분임별 토의 결과, 공감 수, 투표·의견·단어, 질문, 분임별 입장 명단을 엑셀로 열 수 있는 파일로 받습니다.

## 리허설 후 초기화

서버를 끄고 `state.json`을 지운 뒤 다시 켜면 모든 응답·토의 기록·입장 기록이 지워집니다(명단은 `roster.csv`에서 다시 읽음). 분임 관리의 **입장 기록 초기화**는 입장 기록만 지웁니다.

## 내용 고치기

`public/config.js` 한 파일에서 고칠 수 있습니다.

- `EVENT`: 연도, 학교명, 제목, 주제 문구
- `GROUPS`: 분임 주제, 색, 토의 질문 2개
- `FIELDS`: 개인 의견·최종 의견의 세 칸 이름
- `SURVEY`: 설문 수치 (현재 `2026 자공2.0 자체평가 보고서`의 교육주체 설문 10.26.~10.30. 결과)
- `PLAN`: 슬라이드 순서

## 외부 공개 (선택)

```
npx cloudflared tunnel --url http://localhost:8080
set PUBLIC_URL=https://….trycloudflare.com
npm start
```

Render 같은 Node 호스팅에 이 폴더를 올려도 동작합니다(`render.yaml` 포함). 무료 호스팅은 재시작 시 `state.json`이 지워질 수 있으니, 행사 직후 **결과 CSV 다운로드**를 꼭 해 두세요.
